# 工矿帽公司接口联调项目

## 项目说明

本项目基于 `jiekou.md` 从零搭建，包含两个独立目录：

- `backend`
- `frontend`

后端使用 Spring Boot，负责：

- 调用公司接口
- 统一鉴权转发
- 请求参数清洗
- 关键业务参数校验
- 文件下载代理
- WebSocket 语音喊话中继

前端使用 Vue 3 + Vite，负责：

- 按模块测试全部公司接口
- 自动保存 token
- 独立测试 WebSocket 语音喊话
- 展示返回结果与错误信息

## 目录结构

```text
backs/
├─ jiekou.md
├─ backend/
└─ frontend/
```

## 后端运行

要求：

- JDK 17+
- Maven 3.9+

启动：

```bash
mvn spring-boot:run
```

默认端口：`8080`

后端健康检查：

```text
GET http://localhost:8080/api/health
```

## 前端运行

要求：

- Node.js 18+
- npm 9+

安装依赖：

```bash
npm install
```

启动：

```bash
npm run dev
```

默认地址：`http://localhost:5173`

## 联调步骤

### 1. 登录

在“认证与用户”模块中调用 `登录` 接口。

登录成功后，页面会自动提取并保存 token。

### 2. 逐模块测试

依次测试：

- 认证与用户
- 设备与轨迹
- 围栏与报警
- 对讲分组
- GB28181 视频
- 私有 RTC 与文件检索
- LiveKit WebRTC

### 3. WebSocket 语音喊话测试

先在 `GB28181 视频` 模块中调用：

- `生成语音喊话 WebSocket 中继地址`

然后在页面下方 `WebSocket 语音喊话测试` 面板中：

- 连接本地 relayPath
- 发送 Base64 音频数据

## 测试建议

### 单点测试

优先测试：

- 登录
- 获取当前用户
- 获取设备列表
- 获取报警列表
- 生成 LiveKit token

### 集合测试

推荐按以下流程测试：

- 登录
- 查询设备
- 查询围栏
- 查询报警
- 开始直播 / 回放
- 查询 RTC / 文件检索

### 冒烟测试

最小可用链路：

- 后端健康检查通过
- 登录成功拿到 token
- 设备列表可查询
- 报警列表可查询
- 视频相关接口返回正常结构

## 注意事项

- 公司账号密码不要写死在代码里
- 当前实现通过登录接口动态获取 token
- LiveKit 真正入会还需要设备侧与房间侧配合
- 若公司接口字段后续有新增，可直接通过测试台 JSON 请求体扩展
